# LW-06：可配置文字模型与本地自动成片

## 路由与配置

在 Toonflow 原生设置 → 语言模型中配置供应商、OpenAI-compatible 协议、完整 API URL、凭据和模型 ID。自动成片入口明确选择供应商/模型，不绑定 Sol 或 Gemini。展开模型设置可填写预期回执模型；留空要求回执与请求 ID 一致。其他协议明确拒绝，不自动改协议。

本机验收选择 localGemini，http://127.0.0.1:18080/v1；请求 gemini-3.8-flash-high，实测回执 gemini-3.8-flash-n。这是显式名称映射，回执不符合配置即暂停。凭据只存被忽略的 data/settings.json（0600）；任务存配置快照与凭据指纹，既有任务不跟随设置变化。

|步骤|执行器|回执|
|---|---|---|
|剧本拆镜及两种提示词|所选文字模型，本次本机中转 Gemini|模型/请求ID/usage/结构化结果|
|静帧|Flow BELUGA / Nano Banana 2.1|独立稳定job、request、media、SHA256|
|静帧审核|同一已选 Gemini，真实图片输入|accepted、issues、correction|
|单图视频|Flow abra_i2v_8s / Omni|首帧字节hash，8秒720p横屏，无音轨|
|视频审核|同一 Gemini，首帧和1/4/7秒抽帧|抽帧审核，不宣称逐帧或声音检查|
|剪辑导出|已安装的系统FFmpeg|顺序、时长、分辨率、输入和成片SHA256|

本轮不新增依赖、模型、工具或安装包。Toonflow 请求一次文字接口，不自动重发、换模型或做格式修补；既有本机中转站账号池本身的传输重试配置未修改，不将应用层单次请求宣称为上游仅一次尝试。实际返回模型严格核对。生成质量重做与网络重试分开：只在明确获得不合格的真实媒体后，同模型最多再生成2次；未知付费结果暂停核查。

## 一个总任务

工作台「自动成片」输入剧本、选择模型和镜头数量后点击一次，后续由服务推进，关闭对话框或刷新不取消任务。

- POST /api/workflows/flowStart：directory、taskId(UUID)、script、providerId、modelId、shotCount(2..8)。相同ID/输入仅返回旧任务；输入冲突409。
- POST /api/workflows/flowStatus：directory，可选taskId；返回任务和进程内active标记。仅读取，不恢复或重发。
- POST /api/workflows/flowResume：directory、taskId。完成任务验证本地文件后返回；未完成任务核对配置，已完成步骤不重做。待定文字调用不重发；待定媒体先GET原Flow回执，只有已提交/已完成才复用相同幂等ID。原回执缺失或失败则暂停，不新建付费任务。

以上接口均要求同源工作台请求及工作区路径校验。原稿、分镜、步骤、配置快照与回执保存在工作区 tasks/<taskId>/state.json；图片视频保存在原生 assets/<nodeId>/；自动画布独立命名，避免覆盖原画布；成片在 exports/flow<digest>/film.mp4。不是依赖Seko的远程任务。

服务中断后，任务显示“待核查恢复”；显式继续只核查原记录。服务单进程，任务内防重复执行；生成前持久化步骤，写入不明确则暂停。自动画布被其他操作改动会暂停保护编辑；不会覆盖用户改动。

某镜头失败后继续其他独立镜头；全部镜头审核合格才导出。跨不同图片的两个视频必须同时归属该总任务的已审核清单，各自Flow根图片和首帧身份仍独立核验。导出不接收缺镜头、外来回执、重复素材或乱序清单。

## 边界

本卡为静音短片；剧本若要求对白、旁白、歌曲或口型，拆镜后明确暂停，保留原稿，不删除声音需求。对白、固定音色、精确口型与3–5分钟整集仍为后续验收。抽帧审核不是视频每帧正确性的保证；本次真实验收还需执行者独立检查成片。

验证结果见 autoFilmAcceptance.json；编译成功不等于真实验收通过。
