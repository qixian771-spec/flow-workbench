# 成熟漫剧工具接入自有 Flow

## What This Is

为用户制作横屏剧情漫剧，复用成熟平台、官方与玩家提供的工具和 Skill，将其中的生成调用接到用户自己的 Flow，并将素材和任务状态回填到原有工作流。目标是拿到剧本后自动完成生产，交付每集 3–5 分钟、以文戏为主的成片。

## Core Value

成熟创作流程能真实调用自有 Flow、使用返回素材继续工作并自动出片；局部按钮接通不能代表整套工具已完成替换。

## Requirements

### Validated

以下仅是既有实验中验证的能力，不表示整个产品已经交付：

- ✓ Flow 素材上传、回填与原站短片合成在 LibTV、OiiOii、Seko 分别做过实物验证；各平台引用更新限制见 docs/THREE-PLATFORM-LIVE-RESULTS.md。
- ✓ Seko 特定画布首帧视频请求曾接入 Flow，完成生成与回填；常驻扩展在当时版本做过刷新验证。
- ✓ Seko 四镜短对白实验已导出；精确台词、固定音色和口型仍缺少独立完整验收，不能将成片存在视作全部通过。
- ✓ 同镜头、同参考图做过原提示词与 Omni 转换提示词的实际生成对照；尚无质量提升结论。

### Active

- [ ] 梳理成熟平台与 Skill 的调用入口、可复用能力、真实接管范围和缺口。
- [ ] 将目标工作流的生成调用完整接入自有 Flow，覆盖实际需要的图片与视频路径。
- [ ] 根据目标模型能力转换提示词、参考素材与生成参数，并保留输入输出审计。
- [ ] 将真实生成结果、任务状态及素材引用回填到原工作流，驱动自动出片。
- [ ] 支持刷新后的继续运行，并检测网站升级导致的失配。
- [ ] 固定角色音色、精确台词；正面说话镜头必须验证对口型。
- [ ] 从短剧本完整闭环逐步验证到每集 3–5 分钟。
- [ ] 每项任务、里程碑、整体均测试、验收、提交。

### Out of Scope

- 新装 ComfyUI 或其他软件 — 用户明确禁止新增安装。
- 以激烈打斗为首要生产目标 — 用户选择文戏，匹配模型能力。
- 发生失败后改用厂家生成接口、替代模型或伪造完成 — 用户明确禁止兜底。
- 用重复片段拼接、旧素材回填证明新剧本已经生成 — 技术链路实验与内容验收必须区分。

### 规划状态

用户确认初始化设置：阶段讨论后自主执行、标准粒度、顺序推进，研究/计划检查/阶段验收开启，沿用当前模型，规划提交 Git。初始化完成，`gsd-discuss-phase 1` 已收口；正式决定见 `.planning/phases/01-workflow-boundaries/01-CONTEXT.md`。当前尚无执行方案与任务卡。

### 第一阶段已确认的产品选择

- 首版用厂家原站界面和 Skill，只替换生图/生视频到自有 Flow；编剧、拆镜、配音、口型、剪辑暂用厂家能力。
- 比较官方和玩家成熟 Skill，优先流程完整、人工少。暂不限定画风。
- 用户现在没有剧本，输入格式未定；统一短文戏测试稿只作为同条件比较安排。
- 自动检查画面质量，同模型最多重做 2 次；仍不合格则暂停该镜头及依赖，独立镜头继续，全部合格后才能出最终成片。
- 问答始终使用可点击选项，一次一题；无法选择时允许自由说明。

## Constraints

- **流程**：方案 → 拆解任务 → 任务卡 → 执行 → 测试 → 验收 → 提交；里程碑和整体重复验收。
- **真实性**：区分发现接口、实现接管、实测通过与整体验收，保留真实请求和媒体证据。
- **失败处理**：停止并显式报告；结果未知时先核对，不重复扣费、不静默改模型。
- **环境**：使用已有工具，不安装其他软件。
- **沟通**：中文、内联可视化；沿用既有决定，不反复询问已经授权的事项。
- **付费实测**：用户已允许生成消耗；此授权不代表任意无限重试。
