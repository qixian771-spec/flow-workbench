# 目录地图

- `agent/api/`：本机服务接口。
- `agent/services/`：模型、媒体、提示词适配服务。
- `agent/sdk/services/`：操作分发与实际提供方调用。
- `agent/db/`：持久化数据库。
- `extension/`：现有 Chrome 扩展及 Seko 桥。
- `scripts/`：既有各平台集成与审计入口。
- `tests/`：请求、状态、页面桥和转换器测试。
- `skills/`：现有 Flow Kit 工作流，可复用但须确认模型适用性。
- `docs/`：历次实测；旧报告须结合后续记录解释。
- `output/`：本机原始实物与采样证据，通常不进 Git。
- `.planning/`：本次 GSD 规划、阶段讨论与验收记录。
