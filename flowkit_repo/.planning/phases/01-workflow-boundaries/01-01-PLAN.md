## 证据合同（本阶段内部格式，无新增第三方依赖）

所有命令在仓库根目录运行。使用 Python 标准库 argparse/json/hashlib/datetime/pathlib/unittest，不建立通用抓取、插件或调度框架。`evidence.json` 顶层为 `schema_version: 1`、`audit`、`evidence`、`claims`、`candidates`、`selection`、`steps`、`integration_items`、`handoff`。后五类由后续任务写实，当前可为空，但只能验证当前 stage；final 必须检查适用集合非空。

| 记录 | 必填字段与语义 |
|---|---|
| audit | `id` 非空唯一；`started_at` UTC ISO-8601；`code_rev` 当前 Git commit；不能修改 started_at 让旧证据变新 |
| evidence | `id, platform, surface, kind, observed_at, audit_id, code_rev, source_locator, artifact_path, sample, sha256, limitations`；platform 为 libtv/oiioii/seko/local；surface 为 canvas/editor/agent_skill/media/bridge；kind 为 historical_runtime/current_runtime/source/static；unknown 由声明状态表示，不能伪造 evidence |
| artifact_path / sample | 二选一：仓库根相对的真实可读文件路径（含明确只读的本机归档）或非空脱敏采样对象；前者 sha256 为文件原字节哈希，后者为 UTF-8、sort_keys=True、separators=(',',':')、ensure_ascii=False 的 JSON 字节哈希；source_locator 保留原文件定位或去查询串的原站位置。文件缺失不得转成 sample 成功 |
| claims | `id, platform, surface, capability, status, temporal_scope, evidence_ids, limitations, blocker`；status 为 tested/discovered/unimplemented/blocked/unknown；temporal_scope 为 historical/current；每条有非空来源或有实测阻断来源；不可由后置或静态事实推出前置控制 |
| blocker | null 或 `kind, reason, evidence_ids, attempted, next_action`；kind 为 missing_access/missing_archive/contract_unproven/incompatible/unsupported；缺登录只能支持 missing_access，不能支持无法接管 |

`validate_evidence(document, root, stage, now, build=None)` 返回 `contract_valid`、`stage`、`checks`（非空 `{name, passed, detail}`）、`counts`、`feasibility`。本计划仅提供 stage=tracer/matrix，后续原地扩展固定 stage，拒绝未知值。`main()` CLI：`python3 scripts/workflow_evidence_probe.py --evidence <path> --stage <name>`，JSON 输出 stdout；通过退出 0，契约不满足退出 1，参数/读取/解析错误退出 2 且输出原因。`feasibility` 初值 unassessed，不能根据退出 0 自动变 feasible。测试通过注入 now 控制时间，不给生产 CLI 添加伪造日期开关。读取不执行第三方代码、不调用网络、不修改证据输入。

报告每个数据行携带可定位的 claim_id；脚本 matrix stage 校验报告 ID 集合与 claims 一致，禁止“只检查标题/字数”式门槛。证据真实性仍须人工打开来源；哈希有效只能证明采样未被改写。
