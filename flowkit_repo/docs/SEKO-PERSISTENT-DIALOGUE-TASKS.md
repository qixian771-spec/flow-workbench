# Seko 常驻接入与对白短片

日期：2026-10-13。仅更新现有 Flow Kit 扩展和服务，不安装其他软件、模型或依赖。

## 方案

现有扩展在 Seko 页面加载时自动启动已限定工程的接管；现有本机服务保存任务与参考图映射。生成、上传、回填和出片阶段逐项记录，刷新后接续已提交任务，未知写入结果停止检查，禁止重复付费生成或改用其他模型。

对白采用平台可用的固定音色 ID 和精确文本，分别核验配音源文件与最终音轨；对口型使用实际可用接口并检查成片。模型原生对白不能代替固定音色验收。

## 剧本：《等雨停》

场景：雨后的咖啡店窗边。两位成年朋友准备告别，动作克制。

1. 林夏正面近景：“你真的要走吗？”
2. 陈舟正面近景：“明天一早的车。”
3. 林夏正面近景：“那就再陪我等一场雨吧。”
4. 陈舟正面近景：“好，这次我不先走。”

Flow 原始素材每镜 8 秒。实测配音后，口型成片每镜 5 秒，共约 20 秒；留出开口前和说完后的停顿。剧情为原创虚构。

- 新故事 `2110205322326720513`，画布 `2110204684884787202`，Flow 项目 `f10dbc3a-b621-4271-b671-5ea2b4cd22dd`。四次原生调用经扩展自动转至 Flow；生成中刷新后自动续查、下载、校验、上传、原站检查及画布回填，未由代理重新注入接管。
- 首镜原请求 `c921c835-d177-436e-a05f-638e0c0dd400` 超时，原站列表未见对应媒体，回报 `Media not found.`。本机原有工作器仅重查同一 operation，不是再次付费生成。桥接任务明确置为待检查；保留证据并明确重做首镜一次，提示词简化，其余三镜不变。原远端任务结果仍不确定，不能记作生成成功。

- 配音使用 MINIMAX 音色 42（温柔女声）和 30（不羁霸总），每角色两句，语速 1。四次 TTS 成功，原语音时长 1.532542 / 1.358375 / 2.089833 / 2.5 秒。精确文本保存于输入记录。各句加 0.75 秒开口前静音、补齐至 5 秒，计划成片改为四镜约 20 秒；加静音不改变台词。
- 所有配音已上传并通过原站内容检查。固定音色 ID 与输入文本只是输入验收，最终音轨和嘴部时序另行检查。


## 本轮最终实测

- 更新的是现有 0.5.2 扩展与已有常驻服务，未安装软件、模型或依赖。服务重启后连接恢复；Seko 刷新及新标签重开均显示“Flow 常驻接管 · 4 个完成 · 1 个待检查”。待检查项是原首镜超时记录，未冒充成功。
- 明确重做的首镜生成成功后，首次媒体下载超时。本次仅重新下载同一个 media ID，校验 720p/8 秒、完整解码、SHA256 后恢复回填。已改为临时文件下载、完整验证后原子替换；错误信息不泄露签名 URL。
- 原首镜任务仅停止本机继续轮询，远端结果未知，未声称远端取消。其他三镜未重新生成。
- 四个真实 Flow 节点自动编排进 Seko 时间线，首帧取自各自 Flow 视频，不以参考图替代。四句固定音色配音加静音后上传，并通过原站检查。
- 接口适配中发现官方逆遮罩函数不生成单人区域遮罩；改为分别调用官方区域遮罩及逆遮罩函数。修正发生在提交口型任务之前，没有重复提交口型生成。
- 四次 SekoTalk 720p 对口型生成成功，原站余额 110→70，实际消耗 40 点。口型阶段与合成阶段由同一个流程自动推进。
- 原站合成任务 `2110212067111641090` 返回 `GENERATING_COMPLETED`。成片 H.264、1280×720、24 fps、AAC 单声道 24 kHz，容器时长 20.077333 秒、3,139,623 字节，完整解码通过。保留 Seko 水印。
- 成片四段配音与输入 WAV 的相关度分别 0.999832、0.999458、0.999774、0.998909；均超过 0.95 阈值。此项证明原配音保留，不等同于独立逐字识别或声纹身份鉴定。解码音轨含编码尾部填充，20.181333 秒，不应把它误记为视频时长。
- 逐秒帧图显示两个角色交替、说话时有嘴形变化、后段停顿收口。该检查仅验证大体时序，不认证逐音素精准同步。尚无独立 ASR/逐字人工听辨结果，不把输入台词正确写成最终发音完全正确。
- 功能里程碑完成；严格对白质量验收仍有“逐字听辨”和“逐音素口型”两项未认证。本轮有明确排障与恢复记录，不能宣称零干预全自动稳定性已通过。

## 使用范围

2026-10-13 后续更新：Seko 新提交已接入版本化 Omni 提示词转换。当前默认 v1 仅接受显式无对白、无音乐、固定机位、0–3 / 3–6 / 6–8 秒的英文动作提示词；原文保留，其他意图明确停止。不是任意剧本或厂商 Skill 自动翻译。三条真实对比及实验 v2 回填详见 [提示词适配实测](SEKO-PROMPT-AB-TASKS.md)；实验闭口补强没有稳定改善，不作为默认。

现有 Chrome 配置中的 Flow Kit 保持启用，本机 Flow Kit 服务运行，已登记的 Seko 工程在刷新/重开时自动接管。当前只支持映射参考图、横屏、720p、8 秒首帧视频；其他生成选项明确拒绝，不改用原站生成。网站更换构建模块时需重新适配。

生成记录保存在本机服务的 `output/seko-resident/jobs/`，服务重启可读取；页面打开时自动继续下载/上传/回填。上传或创建节点时刷新若导致结果未知，会停止检查，防止重复写入。新工程必须登记自己的参考图映射。

对白流水线保存检查点，可明确恢复；本次持久扩展负责生成接管，不包含“任意剧本直接一键跑整集”的成品工作台。该范围不应扩大宣传。
