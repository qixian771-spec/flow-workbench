# OiiOii × 自有 Flow：真实素材流转与成片实测

日期：2026-10-13。结论：**真实 Flow 素材 → OiiOii 工程 → Agent 自动剪辑 → 原站渲染 → 下载并解码验证**已跑通。尚未实现原站生成请求改道，也未完成六镜头文戏或三站同题比较。

## 当前可行路线与未解项

已跑通路线：既有 Flow 产物 → 官方 CLI 上传 → OiiOii 素材节点 → 原站剪辑 Agent 保存时间线 → 原站渲染 → CLI 下载。

这次由本代理组织多个步骤：创建工程、上传、打开剪辑、发出剪辑指令和渲染指令。原站 Agent 自动执行了剪辑和渲染，尚未做成从剧本输入启动的单一无人值守程序。

后续 R03 实测见下节：已经完成既有素材节点替换及显式更新剪辑后的成片；画布关联元数据仍有陈旧引用。storyboard 与生成请求提交前路由仍未测试。不能把新建上传节点等同于已有镜头回填，更不能把改用原站模型作为失败后的替代。

查询时账号余额仍显示 60，但没有完整结算和用量账单；不能宣布整套流程免费。三个平台的同剧本质量比较仍未完成。
