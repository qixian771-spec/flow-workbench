## 生成接管的确切边界

外部流程已真实读取 Seko 任务文字，调用自有 Flow，收集视频，上传回填并调用 Seko 合成。原生 Seko “生成”按钮、Agent 自动调用生成模型的路径没有拦截或改写。公开 OpenAPI 的策划生片接口没有提供自定义 Flow 参数，但这不能证明未来或其他入口不支持。

当前结果是已验证的混合自动化步骤：已有浏览器登录 + 浏览器自动上传 + 原站模块接口。尚未封装成脱离本次代理会话的无人值守整集服务。构建文件名变化、登录失效、非 8 秒裁剪、多轨配音都必须显式处理，适配器不会悄悄改用其他模型。
